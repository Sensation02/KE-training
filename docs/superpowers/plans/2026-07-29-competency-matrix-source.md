# Матриця компетенцій як джерело — план реалізації

> **Для агентних виконавців:** виконувати задача за задачею, кроки відмічені `- [ ]`.

**Мета:** покласти вихідну матрицю компетенцій у репозиторій і дати переглядати її
в оверлеї на сторінці рівня, без переходу назовні й без мережі.

**Архітектура:** `.xlsx` конвертується разово в `levels/L3/source/L3-competency-matrix.md`;
`build_study.py` парсить цей `.md` і вбудовує як JSON у сторінку рівня тим самим шляхом,
що й питання; `study_template.html` малює оверлей-акордеон, вхід — із вкладки «Чеклист».

**Стек:** Python 3 (стандартна бібліотека), ванільний JS у `study_template.html`.

Спека: [2026-07-29-competency-matrix-source-design.md](../specs/2026-07-29-competency-matrix-source-design.md)

## Глобальні обмеження

- Текст матриці переноситься **дослівно**, друкарські помилки джерела зберігаються.
- Нормалізація дозволена лише одна: послідовності пробілів у заголовках → один пробіл.
- Мітки заливки: 🟩 `#D9EAD3`, 🟨 `#FFF2CC`, 🟥 `#F4CCCC`, ⬜ решта.
- Після конвертації `.md` — єдине джерело істини; парсер читає емодзі, не hex.
- Тека `source/` необовʼязкова: рівень без неї збирається як раніше.
- Стан акордеона не зберігається ні в `localStorage`, ні в KV.
- Мова коментарів і повідомлень збірки — українська, як у решті файлу.
- Залежності не додаються: лише стандартна бібліотека Python.

### Задача 2: Парсер джерела у збірці

**Файли:**
- Змінити: `build_study.py` (нові `SOURCE_DIR_NAME`, `SOURCE_ITEM_RE`, `MARKS`,
  `parse_source`, `source_file`; виклик у `collect_level_data`)

**Інтерфейси:**
- Споживає: `.md` із Задачі 1.
- Дає далі: `data["source"]` = `null` або
  `{"title": str, "sections": [{"col": str, "name": str,
  "items": [{"ref": str, "mark": str, "text": str}]}]}`,
  де `mark` ∈ `green` / `yellow` / `red` / `plain`.

- [ ] **Крок 1: Додати константи поряд із наявними регексами**

```python
SOURCE_DIR_NAME = "source"

# пункт джерела: '- `B15` 🟩 текст' (див. levels/*/source/*.md)
SOURCE_ITEM_RE = re.compile(r"^- `([A-Z]+\d+)`\s*(🟩|🟨|🟥|⬜)\s*(.+)$")
SOURCE_SECTION_RE = re.compile(r"^## ([A-Z]+) · (.+)$")

# емодзі-мітка заливки у джерелі → код для шаблону
MARKS = {"🟩": "green", "🟨": "yellow", "🟥": "red", "⬜": "plain"}
```

- [ ] **Крок 2: Додати `source_file` поряд із `checklist_file`**

```python
def source_file(level_dir):
    """Файли *.md у необов'язковій теці source/ рівня."""
    src = level_dir / SOURCE_DIR_NAME
    return sorted(src.glob("*.md")) if src.is_dir() else []
```

- [ ] **Крок 3: Додати `parse_source`**

Повертає `(data, errors)`. Секція без пунктів, пункт із невідомою міткою, рядок,
схожий на пункт (`- \``), але не зматчений `SOURCE_ITEM_RE`, — усе це помилки,
не мовчазні пропуски: тихо загублений шматок джерела гірший за впалу збірку.
`title` береться з поля `title` у frontmatter.

- [ ] **Крок 4: Викликати з `collect_level_data` і покласти в результат**

Перед `return`: якщо `source_file(level_dir)` дає більше одного файла — помилка
з переліком знайденого; якщо один — `parse_source`, помилки в `errors`;
якщо жодного — `source = None`. Додати `"source": source` у словник, що повертається.
